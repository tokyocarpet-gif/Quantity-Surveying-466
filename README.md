# 積算管理

PDF図面から内装の数量を拾い出し、集計・見積・床材割付・帳票出力を行う日本語デスクトップアプリの新規開発プロジェクトです。

- リポジトリ: https://github.com/tokyocarpet-gif/Quantity-Surveying-466
- 利用環境: Windows
- 開発環境: Windows / macOS
- 状態: v0.30.0。顧客・案件・PDF管理に加え、部屋の数量拾い出し・個数拾い・開口控除・再計算、マウス操作、部位選択、同名統合、仕上げ材マスタを利用できます。物件集計・元ひな形へのExcel転記を利用できます。自社情報・仕様付きの仕上げ材・部位と単位の追加・保存型見積・版履歴・PDFプレビューと保存も利用できます。見積Excel帳票にも対応しています。床材の割り付け（芯割り・芯跨ぎ・壁寄せ）、長尺シート・ロールカーペットの必要量と切り出し一覧、巻き残りを使う切り出し順の調整も利用できます。図面にはシートごとの実測W・Lを寸法線で表示し、切出し寸法や使用巻は一覧で確認できます。長尺シートのW・Lはm・小数1位、Tはmm、ロールカーペットはmm・整数で表示します。規格は最大出荷寸法として扱い、フリーカット／幅なり出荷に応じた使用W×使用L×枚数と面積、選択した部屋の割り付けPDFプレビュー・保存に対応しています。

## 見積表紙の編集

表紙ではExcelのようにセルをクリックして直接編集します。Tabで次の項目、Enterで次の行へ移動できます。「行をまとめて編集」に切り替えると大項目のポップアップも利用できます。大項目の名称・仕様・備考は変更でき、金額は同じ工事名の内訳ページを合算して表示します。

諸経費は固定の最下段欄ではなく、大項目の直下の自由行です。名称・仕様・数量・単位・単価・備考を変更でき、「表紙に行を追加」や最初の空行から運搬費などを追加できます。行の削除には確認が出ます。自由行の金額は見積合計へ一度だけ加算されます。以前の諸経費は表示時に引き継ぎ、保存済みの過去版は書き換えません。数量は小数1位、金額は設定した端数処理で計算します。PDF・印刷・見積Excelに反映します。

表紙は1枚13行（従来の12行＋固定諸経費1行のスペース）で改ページします。最初の自由行だけが次ページに分かれないよう、最後の大項目と一緒に送ります。元の拾い出し数量は変更しません。

新しい見積番号は「2026-0001」のような年別・全案件共通の4桁連番です（1万件以降は桁が増えます）。右上に表示し、改訂しても同じ番号を保持します。既存の番号は維持し、表紙上で手動変更できます。別見積の番号と重なる変更は拒否します。採番の記録はバックアップに含まれます。

## 壁を選んでまとめてPDF

「割り付け → 壁材 → 壁を選んでまとめてPDF」で、現在の図面ページに保存した壁から出力対象を選べます（最大100面）。編集中の場合は先に保存してください。先頭に選択面の数量一覧、その後に壁ごとの展開図・材料明細を新しいページから掲載します。クロス・壁タイル・養生板をまとめてプレビュー・保存できます。材料明細が複数ページになる場合も壁面名・材料名を繰り返します。

数量は各面の計算結果の合算です。面をまたぐ巻き分けや端材の再利用は行いません。従来の1面だけのPDF出力も利用できます。DB構成はv21のままです。

## 開発起動

Node.js 24.15.0（`.nvmrc`）とGitを用意し、WindowsではPowerShell、macOSではターミナルで実行します。

```sh
git clone https://github.com/tokyocarpet-gif/Quantity-Surveying-466.git
cd Quantity-Surveying-466
npm ci
npm run dev
```

WindowsのPowerShellでスクリプト実行ポリシーによるエラーが出る場合は、`npm` を `npm.cmd` に置き換えて実行してください。取得済みの環境を更新するときは、アプリを終了して `git pull --ff-only` → `npm ci` → `npm run dev` の順で実行します。

`npm ci` ではElectronの本体取得、SQLiteのElectron向けビルド、PDF.jsのフォント・CMap・WASMの配置も行います。ネイティブ依存がOSごとに異なるため、`node_modules` をWindowsとMacの間でコピーしないでください。

## 数量を拾い出す

1. 案件のPDFを開き、上部の「縮尺」を選択します。
2. 図面上の既知の長さを2点で指定し、実寸をmmで入力します。「数量を確認」→「反映する」で保存します。
3. 「部屋」を選び、頂点を順にクリックして始点クリック・「確定」・Enterで確定します。「矩形」がONの場合は対角の2点で確定します。
4. 部屋名を入力／履歴から選択し、拾う部位を選びます。「4部位すべて」で一括選択できます。高さ・仕上げ・単価を入力し、「数量を確認」→「反映する」で保存します。
5. 部屋を選択して「開口控除」から壁または巾木を指定します。壁は幅×高さ、巾木は幅を控除します。

保存済みの部屋は「部屋を編集」から高さや形状を変更できます。縮尺を再設定する場合も、変更前後の数量を確認してから保存します。図面やページを移動する際、未保存の編集がある場合は破棄確認を表示します。

ホイールでカーソル中心に拡大縮小、右ドラッグでパンします。描画中は左クリックで点を追加、右ドラッグで移動します。多角形の水平・垂直補助は標準動作です。直前の点から軸に近づくと吸着し、カーソルを離すと斜めにも自由に描けます。切替チェックはありません。縮尺の2点指定にも同じ水平・垂直補助を適用します。矩形には適用しません。拾い中の十字線は図面表示領域の端まで伸びます。

Sでスナップ切替、Backspaceで描画中の直前の点を取り消し、Escapeで描画を中止できます。汎用Undo / Redoではありません。

v0.1〜v0.7系のDBは初回起動時に退避してからv7形式へ更新します。旧形式のバックアップも、検証後に変換して復元できます。詳しくは[開発ガイド](docs/DEVELOPMENT.md)を参照してください。

## 壁の1面・2面を線で拾う

縮尺設定後に「壁（線）」を選びます。1面なら始点・終点の2点、連続する2面なら始点・角・終点の3点を指定し、「確定」またはEnterで確定します。始点へ戻って囲む必要はありません。途中で右ドラッグのパン・水平垂直補助・1点戻すを使えます。離れた壁や高さ・仕上げが異なる壁は別々に登録してください。

部屋名・高さ・仕上げ材を指定して数量を確認します。㎡は指定した線の長さ×高さ、mは線の長さで計算し、必要なら同じ線の巾木も選べます。保存後の線の描き直し・開口控除・数量固定・集計・見積・バックアップ復元に対応しています。同じ部屋名は既存の確認で統合でき、仕上げ別の明細を保持します。床・天井の面積や床材割り付けの対象にはなりません。

**線で拾ったアクセント壁は、既存の部屋の一般壁から自動控除しません。** 一般壁も全周で拾っている場合は、その固定数量を調整するなどして重複を除いてください。

## 壁の養生・ボーダーを延長mで拾う

仕上げ材マスタで「部位：壁」「単位：m」として材料を登録し、拾い出しの壁の仕上げから選択します。「壁の拾い方」が「延長（m）：周長」に切り替わり、高さを掛けずに部屋の周長を計算します。手入力の場合も拾い方を選べます。4m×3mの部屋なら14mです。袖壁は線の長さ×面数を加えます。材料の板枚数やクロス幅による使用長の換算ではありません。

貼らない開口は「開口控除」で幅×箇所数を差し引きます。ボーダーの高さにかからない窓などは控除しないでください。一部の壁だけ貼る場合は「壁（線）」でその壁の始点・終点を指定します。

㎡とmを切り替える場合は、数量確認に変更前の単位を表示し、開口控除を新しい単位で再計算します。壁の固定数量は単位が異なるため解除し、警告を表示します。「反映する」までは保存内容を変更しません。集計・見積・帳票にはmで引き継ぎ、㎡と混ぜて合計しません。既存の部屋・過去の見積は自動変更しません。

## 高さ・袖壁・縮尺

新しい部屋の高さは、この物件で前回確定した高さを初期値にします。「高さの履歴から選択」で直近100種類から選べます。未使用の物件は2400mmです。「反映する」まで履歴を保存せず、名前・仕上げなど高さ以外の編集だけでは前回値を変更しません。部屋を削除しても履歴は残り、ページ切替・再起動・バックアップ復元後も利用できます。

厚みのない袖壁を部屋の輪郭に往復線として入れると、外周が自己交差して面積が定まらなくなるため確定を止めます。次の手順で外周と分けて拾います。

1. 袖壁の往復線を入れず、部屋の外周だけで確定します。描画中は「1点戻す」で修正できます。
2. 部屋を選択して「袖壁」を押し、袖壁の始点と終点をクリックします。
3. 片面／両面、高さ（空欄は部屋に連動）、巾木を拾うかを指定し、数量を確認して反映します。

袖壁は「長さ×面数×高さ」を壁に、「長さ×面数」を巾木に加算します。各部位が拾う対象として選択されている場合だけ加算します。床・天井の面積は変わりません。右の袖壁一覧から設定変更・削除ができます。仕上げ・単価はその範囲の壁・巾木を使います。小口、外周や別の袖壁との重なりは自動調整しません。端点の移動は削除して描き直します。

縮尺確定後は上部に「縮尺 約1/100（PDF原寸）」のように表示します。校正した実寸とPDFの原寸サイズから計算するため、画面のズーム倍率では変わりません。PDF自体が拡大縮小されている場合、図面に印字された縮尺と異なることがあります。

## 同名部屋と確認画面

同じページに同名の部屋がある場合、「統合して数量を確認」または「別の部屋として登録」を選択します。確認画面では今回の変更対象を表示し、統合時は合計数量も表示します。縮尺変更では、そのページで影響を受ける部屋を表示します。

統合は複数の範囲を同じ部屋として合算する処理です。図形の重なる面積や共通の辺を自動で差し引く処理ではありません。各範囲の形状・高さ・仕上げ・控除・固定数量を保持します。左の一覧は部屋合計、右の「統合した部屋の範囲」で範囲を選んで編集・削除します。部屋名の変更は統合した全範囲に反映します。異なるページ・図面の同名部屋は独立して保持します。

## 仕上げ材マスタ

案件画面または拾い出し画面の「仕上げ材マスタ」を開きます。「物件マスタ」→「共通から選ぶ」で必要な材料をチェックし、一括で取り込みます。共通マスタにはクロス・塗装・巾木・床材など9件を単価未設定で用意しています。材料の追加・編集・削除にも対応しています。共通マスタだけを管理する場合は「設定・データ管理」からも開けます。

材料の登録・編集では、Enterで材料名→仕様→幅→長さ→厚み→単価の入力欄へ進み、最後は「材料を保存」へ移動します。移動だけでは保存せず、保存ボタンを押して確定します。部位・材料の種類・単位の選択はマウスまたはTabで行えます。日本語変換中のEnterは文字の確定に使います。

取り込んだ材料の名称・単価は物件側で調整できます。拾い出し時は部位ごとの「物件マスタから選択」を使い、その場で手入力もできます。共通→物件、物件→拾い出しは採用時の値をコピーするため、マスタの編集・削除で既存の拾い出しが書き換わることはありません。マスタと部屋名履歴はバックアップに含まれます。

## 集計数量をExcelへ転記する

集計画面の「表示中の集計をExcel保存」から大項目（初期値：内装仕上工事）を入力して保存します。CSV保存ボタンを置き換えました。現在の絞り込み条件に一致する数量を、表示タブにかかわらず部屋×仕上げでまとめて出力します。

元の「基本見積もり書.xlsx」を複製し、「表紙」「内訳書」「マスタ」の3シートを残します。品名欄は部屋名と部位、仕様・規格・寸法欄は仕上げ材と仕様・規格。部屋ごとに天井・壁・巾木・床・追加部位の順で並べます。同名でも別登録の部屋を名前だけで合算せず、同名別室は備考に図面・ページを記載します。

数量は小数1位へ四捨五入した数値を転記します。金額はその数量×単価を円単位に四捨五入するExcel式です。元明細を小数3位で計算する集計画面の参考金額とは差が出る場合があります。登録単価は引き継ぎ、未設定の単価・金額と対応する小計・合計は空欄にします。0円は0円として扱います。

Excelで内訳の単価を入力すると表紙の大項目金額と合計に連動します。空欄ページへ後から追加した数量も合計に含めます。諸経費は表紙の行へ数量・単価を入力してください。宛先・工事名は案件から、自社名・住所・電話・見積期限・支払条件は入力済みの設定から引き継ぎ、未設定なら元のひな形の内容を残します。ひな形に専用欄のないメール・担当・登録番号・その他条件は転記しません。保存日の日付を使用し、開き直しても自動更新しません。Excelでの編集はアプリへ戻りません。

元の内訳10ページ（1ページ25行）と表紙の空欄行を削除せず、行高・列幅・罫線・フォント・結合セル・マスタ候補・図形・印刷設定を維持します。転記に使うページには大項目を繰り返します。長い仕様は既存の次の空欄行へ続け、数量・金額は重複させません。10ページを超える場合だけ同じ枠のページを追加し、改ページ・印刷範囲・入力候補・表紙の合計式を延長します。空欄ページも元の印刷範囲に含むため、必要に応じてExcelで印刷ページを指定してください。

元のひな形・拾い出し・見積データは変更しません。ローカルの `resources/templates/summary.xlsx` に元ひな形をそのまま保存し、ビルド時は同梱リソースへコピーします。Excel・iCloudへの接続なしでWindows・Macで生成できます。このリソースには元の自社情報や候補一覧も含まれます。内訳は80ページ、数値はExcelで正確に扱える有効15桁を上限とします。

## 物件全体の数量集計

案件画面の「数量集計」から開きます。保存済みの全PDF・全ページが対象です。「部屋×仕上げ」「仕上げ別」「部屋別」「図面別」を切り替え、図面・ページ・部屋・部位・確認事項や、部屋名・仕上げ名・図面名の検索で絞り込めます。上部の数量・参考金額も表示条件に連動します。

統合した部屋は各範囲を合算します。同名でも別登録した部屋や別ページは区別し、部位・仕上げ名・単位・単価が異なる明細は別行にします。袖壁・控除・固定数量を反映し、単価未設定と0円を区別します。過大控除で負になった元明細は、合計が正でも確認事項に残ります。

部屋名の後ろの「部屋1」などの管理番号は表示しません。同名の別部屋は内部IDで区別します。

「部屋×仕上げ」では数量行をクリック、または「仕上げ・単価を編集」で、物件マスタから材料を選択したり仕上げ名・単価を直接入力したりできます。「保存して反映」で、その行に含まれる元明細と部屋の仕上げ設定を更新し、集計金額を再表示します。統合行は含まれる範囲をまとめて更新します。数量・控除・固定値・他部位・マスタの内容は保持します。キャンセルでは保存しません。

「内訳」→「図面へ」で該当ページ・部屋を開いて編集できます。「集計に戻る」で絞り込み条件を保って最新の数量を再取得します。

集計の保存ボタンは「表示中の集計をExcel保存」です。現在の絞り込みを維持して元の見積ひな形へ転記します。出力前に元データが変わった場合は再集計を求めます。

現段階の参考金額は税別です。元明細ごとに正味数量を小数3桁、数量×単価を円単位で四捨五入して合算します（負数のちょうど半分は絶対値を大きくする方向）。表示形式を変えても合計は同じです。集計行の数量×単価と金額に端数差が出る場合は、内訳の元明細で検算できます。元数量・控除もそれぞれ丸めるため、表示上の差し引きと正味数量に0.1単位の差が出る場合があります。保存された幾何計算値は変更しません。保存型見積では数量を小数1桁に採用してから金額計算するため、集計の参考金額と異なる場合があります。

### 集計積算書をPDFで保存

集計画面の「集計積算書PDF」からプレビューを開き、「PDFを保存」で出力します。物件全体を出す場合は「条件を解除」し、表示形式を選んでからPDFを作成してください。選択中の表示形式・図面・ページ・部屋・部位・検索条件を反映します。

A4横で案件名・顧客・案件担当・自社情報・作成日時・対象条件・部位別合計・集計明細をまとめます。元数量・控除・正味数量・仕様・規格・単位・単価・参考金額を載せ、部屋別／図面別では見出しを付けます。数量は小数1桁、金額は集計画面と同じ計算結果です。単価未設定は未確定、固定数量と負数は明示します。

プレビューの作成前に集計の更新を検知した場合は、閉じて「再集計」してください。保存時は確認したプレビューの内容をそのまま保存します。集計積算書の金額は元明細の計算数量から合算するため、数量を小数1桁で採用する見積とは端数差が生じることがあります。

## 自社情報と仕上げ材の追加項目

左サイドバーの「設定・データ管理」→「自社情報を登録・編集」で、建設業許可・消防庁認定・会社名・郵便番号・住所・電話・FAX・メール・担当者・登録番号に加え、見積有効期限（例：発行日から30日間）・支払条件・その他の基本条件を保存できます。新しく作る見積の発行者と取引条件へ引き継ぎ、見積ごとにも編集できます。保存済み見積は自動変更しません。 許可・認定を上段、会社名を大きく、その下に郵便番号・住所・同じ行のTEL/FAXを表示します。入力画面に表示プレビューがあり、Enterで次の入力欄へ移動します。既存見積は「設定」→「自社情報を反映」で内容を確認して適用できます。反映後の会社欄をクリックすると見積専用の会社情報を編集でき、元の自社情報や旧版は変更しません。PDF・印刷は同じ表示を使用し、見積のExcel出力にも許可・認定、強調した会社名、連絡先を引き継ぎます。

案件の作成・編集で担当者を入力できます。案件一覧・案件の見出しにも表示し、案件検索の対象になります。

集計上部の部位別合計は、個数の部位を追加しても1行で表示します。画面幅に応じて配分し、収まらない場合は横スクロールで確認できます。

仕上げ材マスタの「部位を追加」「単位を追加」で選択肢を登録し、材料ごとに名称・仕様・規格（幅、長さ、厚みの順、mm）・単位・単価を保存できます。仕様は文章、規格は各寸法を自由入力し、不要な寸法は空欄にできます。共通から物件へ取り込むと、これらをすべてコピーします。材料選択時に仕様と規格を「品番ABC ／ 450×900×2.5 mm」のように一欄へまとめ、拾い出し、集計とCSV・PDF、見積とPDF・Excelへ引き継ぎ、同じ材料名でも仕様が異なる数量は分けて集計します。

見積・拾い出し・集計編集の仕上げ材は、一段の入力欄で自由入力と物件マスタ選択ができます。右端の矢印で一覧を開き、入力すると材料名・仕様などで絞り込みます。同名材料は仕様・単価で選び分けられます。マスタ選択時に仕様・単価などを反映し、自由入力では名称だけを変更します。見積では追加部位・単位を含む材料も選べます。図面からの自動拾いは天井・壁・床が㎡、巾木がmで、対応する部位・単位の材料だけを候補に表示します。追加部位の自動数量計算は未対応です。

## 見積の作成・保存

数量集計の「この集計から見積を作成」で、表示中の数量を第1版として取り込みます。保存履歴・作成元は従来どおり保持し、元の拾い出しを変更しても保存した見積は自動変更しません。

A4横（297×210mm）のモダンな帳票で、表紙12行・内訳書1枚23行の固定枠を使います。行をクリックするとポップアップで必要な項目だけ、または行全体を編集できます。「反映して次の行」で同じ内訳書の次行へ連続入力できます。キャンセルでは変更しません。「セル編集に切り替え」で帳票上の個別編集も利用できます。編集画面・PDF・印刷は同じ帳票部品とページ割りを使います。品名は左寄せ、任意の部位は品名欄の右側です。仕様1〜3、メーカー、部屋、数量、単位、単価、備考、直接入力の項目番号を保持します。品名欄の候補から物件マスタの材料を選ぶと、仕様・部位・単位・単価を反映します。

Enterは同じ項目の次の明細、Tabは次の入力項目、Shift併用で逆方向に進みます。Escはセル編集を取り消し、備考・取引条件などの複数行欄はAlt+Enterで改行できます。数量は小数1桁に丸めて採用し、単価未設定と0円を区別します。Excelからは帳票の列順（No.、品名、仕様、数量、単位、単価、金額、備考）で複数セルを貼り付けできます。金額列は無視して再計算し、不正な値があれば貼り付け全体を取り消します。部位や追加仕様は個別入力できます。

「元に戻す」「やり直す」は確定した編集を100操作まで保持します。セル編集中は入力欄の標準Undo、セル外ではCtrl/Cmd+Z・Shift+Ctrl/Cmd+Zを利用できます。保存・保存履歴の切替で操作履歴をリセットします。追加は空行の「ここに明細を入力」または帳票下の「明細を追加」から行います。空き枠がある場合は最終明細でEnterを押しても次行を追加します。23行が埋まっても内訳書を自動追加しません。「内訳明細書を追加」で空の23行の帳票を作成します。追加した空の帳票も保存・PDFに含まれ、行の削除でほかの帳票の明細が移動することはありません。旧形式の見積を開いた場合は工事区分ごとに23行ずつ配置し、元明細を保持します。削除は各行の右端の「削除」から確認後に実行し、最後の明細を削除した場合は入力用の空行を残します。行を選んで「行の詳細」を開くと、追加仕様・メーカー・部屋・工事区分の入力と行の順序変更ができます。保存履歴・税率・端数処理は「設定」にまとめ、保存後も表示ページを維持します。

内訳書を基本の明細データとします。少量の場合は「表紙へ転記」を開いてチェックで最大12行まで選び、「選択した明細を表紙で編集」で表紙へ切り替えます。残り枠を表示し、13行目の選択は無効にします。転記はデータの複製ではありません。表紙形式では選択行のみを見積金額に計上し、未選択行は裏で保持します。「全明細の内訳書編集に戻す」と保持した全行を再び計上します。内訳形式の表紙には工事一式と諸経費を載せ、内訳は作成した帳票ごとに工事名と小計を付けます。

諸経費は表紙に金額を直接入力します。明細単価は税抜で保持し、表紙の税抜／税込表示を切り替えます。新規見積の税率は10%、税端数は切り捨てで、「設定」から変更できます。古い見積の税率・保存内容は保持します。

PDF・印刷に含める帳票は「表紙」「内訳書」の独立したチェックで指定します。変更を保存した後に「PDFを作成」で保存するか、「印刷」でシステムの印刷ダイアログを開きます。PDF確認は出力確認用で、編集用の別グリッドはありません。フッターはページ番号のみです。内訳書には諸経費・消費税の注記を載せません。長い文章が固定の行枠やA4の範囲を超える場合は出力を止め、文章を短くするよう案内します。

見積と全版・作成元はバックアップに含まれます。画面内移動や版切替では未保存編集の破棄確認を表示します。強制終了時の未保存編集回復、Excelファイルの読み戻し、自由な数式、範囲ドラッグ編集は未対応です。見積画面のExcel出力ボタンは廃止しました。

## 柱型・ルーバーなどの個数拾い

図面上部の「個数」または左の「個数を追加」を押し、対象の位置を1点ずつクリックします。部位と名称・仕上げ材は空欄から入力・選択します。縮尺は不要で、番号付きのマークを表示します。名称・部位・仕様・単位（個・本・箇所・枚・基・台など）・単価と、必要に応じて部屋を指定し、「個数を確認」→「反映する」で保存します。個数用の単位を持つ物件マスタからも材料を選べます。

「点を追加」「点を取り消す」「最後の点を戻す」で数え直せます。変更を保存する前にページ移動する場合は破棄確認を表示し、登録済みの個数拾いの削除も確認を挟みます。1項目につき1〜10,000点を保存できます。

個数は位置・属性とともにページごとに保存し、集計・CSV・見積へ引き継ぎます。異なる単位は別集計です。縮尺を変更しても個数は変わらず、関連付けた部屋を削除しても個数は「部屋未指定」として残ります。柱型の表面積やルーバーの長さを寸法から求める計算は、この個数機能には含みません。

### パンと拾い出しツール

「パン」を選ぶと左ドラッグで図面をつかんで移動できます。右ドラッグはどのツールでも図面移動に使えます。部屋の点指定や個数拾いの途中でも、パンを選んで移動し、元のツールに戻って続きを拾えます。

部屋の数量拾いは先に「縮尺」で既知の長さを設定します。「部屋」で頂点を順にクリックして「確定」、または「矩形」を有効にして対角の2点をクリックし、部屋名などを入力して「数量を確認」→「反映する」で保存します。仕上げ材マスタの読み込みに失敗しても、名称・単価を手入力して作業できます。

### 割り付けの範囲を囲い直す

割り付け画面で部屋を選び、左の「割り付け範囲を囲い直す」を押します。外周の頂点を順番にクリックし、始点クリック・Enter・「範囲を確定」のいずれかで閉じます。水平・垂直補助、ホイールズーム、右ドラッグのパン、1点戻す・Backspaceに対応します。「囲い直しをやめる」またはEscapeで描画を中止できます。

確定後は新しい範囲で材料配置・使用数量・壁からの寸法・PDFを計算します。「割り付けを保存」で次回も使えます。元の拾い出し範囲は灰色の破線で残り、拾い出し・集計・見積の数量は変更しません。「拾い出しの範囲に戻す」で元へ戻せ、確定・復帰は「ひとつ戻す」でも取り消せます。範囲の変更時は基準壁と移動量を初期化します。

同名で統合した部屋は、代表となる範囲を一つ選び、割り付けたい全体の外周を囲ってください。専用範囲は選択した範囲に保存します。他の範囲の配置とは自動統合しません。離れた複数の領域や穴を含む形状は、今回の単一外周では表せません。

### タイルのずらし貼り

割り付け画面の材料設定にある「貼り方」で、通し貼り・馬貼り（1/2ずらし）・1/3ずらし・1/4ずらしを選べます。W（幅）方向またはL（長さ）方向へ、目地を含む寸法を基準に各段を順にずらします。1/3は3段、1/4は4段で元の位置に戻ります。

芯割り・芯跨ぎは基準点を通る段に適用します。壁寄せ・回転・図面上のドラッグ・矢印の微調整・右パンと併用できます。表示と真物・切り物・使用元材の枚数、保存・再表示・PDFへ反映します。端材の再利用は従来どおり計算しません。ロール材に貼り方は適用しません。ヘリンボーンにも対応しています（下記参照）。

貼り方のない従来の割り付けは「通し貼り」として開き、保存済みの馬貼り・ずらし貼りも元の配置を維持します。

### 床材を割り付ける

図面一覧の各カードに「拾い出し」「割り付け」があり、それぞれ専用画面を開きます。拾い出しで部屋と縮尺を保存した後、図面一覧へ戻り「割り付け」を選びます。ページは画面上部、部屋は左サイドバーの先頭で選択します。図面ページと部屋の外周を使って長方形・正方形の材料を格子状に配置します。

未保存の調整がある状態で部屋・ページを変えたり図面一覧へ戻ったりすると、破棄確認を出します。部屋や縮尺がないページには拾い出し画面への入口を表示します。

- マスタの「仕様」の後に「規格（mm）」を配置し、幅・長さ・厚みを自由入力します。固定寸法ボタンはありません。各寸法は省略でき、共通から物件へ取り込む際にも引き継ぎます。目地幅は割り付け画面で候補選択または自由入力します。材料を切り替えても設定中の目地幅を保持します。
- 割付画面で物件マスタから材料を選ぶと寸法を適用します。新規の割付でマスタ寸法がない場合や、寸法未登録の材料へ切り替えた場合は幅・長さを空欄にします。両方の有効な寸法を入力するまで計算・保存を行いません。保存済みの割付を開いた場合は保存時の寸法を保持します。マスタ変更は保存済みの割付には自動反映しません。
- 芯割りは目地芯、芯跨ぎは材料の中心を部屋の中心に合わせます。横・縦を別々に選べます。凹形状の中心は、回転後の外周を囲む長方形の中心です。
- 壁寄せは番号を表示した基準壁を選択します。壁に沿う向きを基準に、壁から真物で配置します。斜めの壁にも対応します。
- 左ドラッグで配置移動、右ドラッグで図面パン、ホイールでカーソル中心のズーム。1/10/100mmの移動ボタン、横縦のmm入力、回転角度で微調整できます。移動の横縦は材料の方向基準です。図面にフォーカスして矢印キーでも移動でき、「ひとつ戻す」で直前の調整を戻せます。
- 緑が真物、橙が切り物です。使用元材は各切り物マスに1枚を使う場合の枚数です。端材の再利用、予備、箱単位、市松などの色分け、柱型や床の穴の自動控除は含みません。拾った外周の面積を使い、統合した部屋は範囲ごとに保存します。
- 「割り付けを保存」で部屋IDに紐づけて保持し、再表示・バックアップ復元に対応します。未保存で閉じる場合は確認します。部屋や縮尺が変わった場合は現在の形状で再計算し、確認後に保存します。部屋削除時はその部屋の割付も削除します。割付から見積への数量反映は未実装です。割付図と使用材料のPDF出力に対応しています。

### 壁クロスの展開図・使用数量

割り付け画面の上部で「壁材」を選び、材料の種類を「クロス」にします。部屋を選んで平面図の一辺をクリックするか、「2点で壁を指定する」で壁の始点・終点をクリックすると、長さと高さから正面の展開図を作ります。拾い出しで保存した縮尺を使用します。右ドラッグでパン、ホイールでズームできます。赤い始点が展開図の左端です。「左右を反転する」で向きを変更できます。

壁高さは部屋の高さを初期値とし、変更・履歴からの選択ができます。窓・ドアは左端からの距離、床からの高さ、幅、高さで配置します。保存した壁はページ単位で一覧から選べます。拾い出しの数量・床材割り付けは変更しません。

仕上げ材マスタの「壁クロスの割り付け規格」を有効にすると、有効幅、縦・横リピート、柄合わせ方式（なし・ストレート・ステップ）、ステップずれ、巻き長さを共通・物件マスタへ保存できます。半リピート以外のずれも指定できます。マスタは割り付けへコピーするため、後からマスタを変えても保存済みの配置は変わりません。有効幅は継ぎ合わせ後の幅、横リピートは仕様表示用です。

展開図では貼り始めのずらし、上下の切りしろを調整し、施工面積・必要巾数・裁断計・柄出し等の余裕・必要長さを確認できます。巻き長さがあれば、施工順に裁断する巻番号と各巻の使用長さ・残りも表示します。裁断寸法はmm、合計m数は小数1位で表示します。壁ごとに保存、PDFプレビュー・保存ができます。

計算は端材を使い回さない余裕込みの数量です。柄合わせ時は壁高さ＋上下切りしろを縦リピート単位に切り上げ、ステップずれに合わせる裁断間の余裕を追加します。巻き始めの柄出しには最大1リピート分を確保します。窓・ドアは施工面積から控除しますが、材料は原則全高で計算し、巾全体が床から天井まで開口になる場合のみ除外します。特殊な柄合わせ、斜め天井、複数壁にまたがる柄合わせ、端材再利用は未対応です。

壁クロスはDB v19以降に対応します。現在のDBは貼り始めの左右切替に対応したv21です。

### 壁タイル・プラベニアの割り付け

「割り付け → 壁材」で壁を選び、「材料の種類」を「壁タイル」または「プラベニア・板材養生」に切り替えます。マスタの「タイル・その他」で登録したW・L・Tを選ぶか、自由入力します。規格未設定の場合は空欄のまま表示し、寸法が揃うまで保存・PDF出力はできません。

壁タイルは通し貼り、馬貼り、1/3・1/4ずらしと目地幅に対応します。養生板は通し貼り・目地なしです。共通で90度回転、左下基準／中心目地／中心材料、横・縦の移動量を調整できます。「施工範囲の床からの高さ」と「施工高さ／養生高さ」で腰壁・部分養生を設定します。高さが空欄の場合は壁の上端までです。

展開図は全形を緑、カット材を橙で表示し、各材料の番号とカット外形の横×縦寸法を一覧に対応させます。施工範囲に重なる窓・ドアを控除し、開口に完全に入る材料は除外します。開口で分割・切欠きが残る場合は、同じ番号の部分を1枚の元材から取る計算です。施工面積、実際の材料面積、必要元材・全形・カット枚数、元材面積・端材面積を表示し、保存・PDFプレビュー／保存に対応します。

端材の他の位置への使い回し、切断刃幅、予備枚数・箱単位の発注丸めは含みません。カット表の外形寸法だけでは切欠き形状を表せないため、加工位置は展開図と合わせて確認します。壁タイルのヘリンボーンは未対応です。

DB v20へ更新する前にrecovery/before-schema-v20のバックアップを自動作成します。既存クロスの保存JSONや、材料・拾い出し・床材配置の行データは変更しません。v20データとバックアップを使用するWindows/Macはv0.26.0以降にそろえてください。

### 壁材の貼り始めを左右で切り替える

壁材の設定にある「貼り始め」で「左から／右から」を選べます。クロス・壁タイル・プラベニアに共通です。右から選ぶと右側から材料と番号を並べます。端基準・ずらしなしでは右端から幅なりに配置し、左側に端部の切り物を残せます。壁の向きや開口の左端からの距離は変更しません。既存の「左右を反転する」は展開図を見る向きを変える別の操作です。

クロスは選んだ側から巾数・ステップ柄・巻割りを計算し、貼り始めのずらしも開始側に適用します。タイル・板材は端基準が「右下から」に変わり、中心基準やずらし貼りにも対応します。横移動は左右どちらを開始側にしてもプラスが右、縦移動はプラスが上です。展開図とPDFには開始方向を表示し、保存・再表示・Undoに対応します。

既存データは左始まりとして読み込みます。DB v21へ更新する前にrecovery/before-schema-v21へ自動退避し、既存の行データは書き換えません。v21データとバックアップを開くWindows/Macはv0.27.0以降にそろえてください。

### ヘリンボーン貼り

材料の幅・長さに長方形の寸法（例：150×600 mm）を入力し、「貼り方」で「ヘリンボーン（90°組み合わせ）」を選びます。長方形を直角に組み合わせる配置で、0°では材料の長辺が基準方向に対して斜め45°になります。幅と長さの入力順を入れ替えても同じ配置です。正方形は入力案内を表示し、配置・保存を行いません。

「柄の中心」で部屋を囲む長方形の中心、「壁を基準」で壁の端を柄の起点にできます。基準点は2枚を組み合わせる角です。「柄を90°回転」、任意角度、左ドラッグ、移動量・矢印で配置を調整します。壁基準も真物から始まる保証はなく、図面を見ながら切り物の位置を合わせます。右ドラッグは図面のパンです。

目地幅を含めて配置し、真物・切り物・使用元材、保存・再表示・バックアップ・PDFへ反映します。端材の再利用・予備枚数・箱単位・材料の印刷柄の合わせは含みません。斜めに端部を加工した材料を使用するフレンチヘリンボーンは未対応です。

ヘリンボーン保存はDB v18以降に対応します。現在のDBは貼り始めの左右切替に対応したv21です。既存の馬貼りや拾い出しの行データは保持します。

### 割り付け基準点から壁までの寸法

ピンクの十字（中心点、壁寄せの場合は配置の起点）から、割り付けの縦・横方向に最初に当たる壁までの寸法をmmで表示します。図面に寸法線と壁番号を表示し、左側にも四方向の値を一覧表示。寸法線はチェックで表示・非表示を切り替えます。移動・回転・部屋切替に追従し、パン・ズームで実寸は変わりません。凹形状や斜め壁は実交点を使い、基準点が部屋外の場合は案内を表示します。短い寸法線は図面の文字を省略し、左側で値を確認できます。

### 長尺シート・ロールカーペットの割り付け

マスタの材料の種類で「長尺シート」「ロールカーペット」を選び、規格の順にロール幅・巻き長さ・厚みをmmで入力します。20m巻は20000mmです。巻き長さは任意で、共通から物件へ取り込む際も引き継ぎます。仕様と規格は引き続き集計・見積で一欄へまとめます。

割り付けで材料を選ぶと種類・ロール幅・巻き長さを採用し、目地を使わず幅方向に継ぎ目を並べます。芯割り（中心に継ぎ目）・芯跨ぎ（中心に材料）・壁寄せ、90°回転・任意角度、左ドラッグと数値で継ぎ目位置を調整できます。ロールの長さ方向は矢印で表示。縦の移動は基準点のみを動かし、シートは部屋の端から端まで敷きます。

切りしろは両端それぞれのmm数です。各幅帯の最初から最後までの敷設長に2倍を加え、切出し長を1mm単位で切り上げます。図面のシート番号に対応する切り出し一覧、必要延長、ロール幅全体での必要面積、番号順に切り出す場合の参考巻数を表示します。部屋の正味面積と必要数量は別表示。巻き長さ未設定でも延長・面積は算定でき、1枚の切出しが巻き長さを超える場合は警告して巻数を未算定とします。

切り出し一覧はクリックで開閉でき、全体表示は図面を表示領域の縦横に収めます。配置は部屋ごとに保存し、既存のタイル配置・拾い出し・見積数量を自動変更しません。凹部の空白をまたぐ帯も連続した1枚として扱います。端材再利用・柄合わせ・幅方向の重ね代・穴の控除・継ぎ足し位置の自動配置は含みません。

### 拾い出し数量を見積内訳へ転記

「この集計から見積を作成」で、品名に部屋名、仕様1に仕上げ材、仕様2に材料の仕様・規格を転記します。部位・数量・単位・単価は引き継ぎます。内訳のマスタ選択は仕様1から行い、品名を保持したまま材料と規格を更新します。この転記形式は新しく作る見積に適用し、保存済みの見積は変更しません。

### 部位・単位の一覧と編集

仕上げ材マスタの「部位の一覧・編集」「単位の一覧・編集」で登録済み項目を確認し、追加した項目を改名できます。改名は共通・全物件の材料マスタへ反映します。天井・壁・巾木・床、㎡・m・式・個は数量計算用の基本項目として固定です。保存済みの拾い出し・見積は変更しません。見積一覧・見積編集の「マスタ」からも開け、編集中の見積を保持したまま更新した候補を使えます。
