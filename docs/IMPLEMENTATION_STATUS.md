## v0.19.0の壁の延長m拾い

壁の仕上げJSONに任意のunit（㎡／m）を保存します。旧データは㎡のまま。壁mは外周長＋袖壁長×面数を計算し、高さ・材料幅は使いません。壁のマスタ候補にmを追加し、選択時に単位・計算を引き継ぎます。数量確認・同名統合・左の部屋一覧は㎡とmを区別し、集計編集でも計算単位を保持します。

単位を切り替えたときは固定数量を解除し、控除を幅×高さ×箇所数または幅×箇所数で再計算して、反映前に警告します。DB v14へ移行前バックアップ付きで更新し、既存の行・JSONは書き換えません。旧バックアップの検証・復元を維持します。

## v0.18.0の最大出荷寸法・使用材料・割り付けPDF

規格W・Lを最大出荷寸法として扱い、割付W（継ぎ目の間隔）と最大出荷Wを分離しました。カーペットは割り付けごとに幅なり出荷／フリーカットを選択できます。幅なり出荷と長尺シートは最大出荷W、フリーカットは各帯の実測最大幅をmm単位で切り上げたWを使用します。使用Lは実測最大長に両端切りしろを加えた長さです。同寸法のW×L×枚数と使用面積を集計します。

最大出荷Lは各枚の上限確認と切出し組合せの参考値に使用し、最大Lを全量購入する面積計算はしません。フリーカットは各使用寸法で集計し、幅の異なる材料を同じ巻として合算しません。最大Wを超える割付Wは拒否し、最大Lを超える枚は警告します。自動の横継ぎ・幅方向の重ね代・柄合わせ・端材再利用は未実装です。

選択した部屋について、A4横の割り付け図と使用材料内訳をPDFプレビュー・保存できます。図面は元PDFから部屋周辺を切り出して実測寸法線を重ね、画面のズーム・パンに依存せず生成します。内訳は最大出荷寸法、出荷方法、使用W・L・枚数・面積と各シートを表示し、長い表は次ページへ続きます。タイル割り付けも図と枚数を出力できます。

PDFは編集中の配置も対象にできます。部屋の形状・縮尺・配置の版を出力前に検証し、古い画面からの作成を拒否します。プレビュー時のPDFバイトを保存するため内容が一致します。保存キャンセル・保存先保護は既存の帳票と共通です。PDFを作成しても配置・拾い出し・見積は変更しません。

DB v13で新しい配置JSONを旧版から保護します。rollCutModeは旧配置でwidth、maxWidthMmは旧配置でnull（元の割付Wを最大幅として読み込む）です。移行前にbefore-schema-v13を作り、既存の行・JSONは書き換えません。

検証：110件の自動テスト、型検査・ビルド・書式チェック、Electron E2Eが成功。幅なり／フリーカットの数量、最大出荷寸法、保存・復元、PDFプレビュー・保存・キャンセルと元データ保持を確認しました。実際のPDFを2ページとも画像化し、文字の重なり・見切れがないことを確認しました。Windows実機は未確認です。

## v0.17.0の実測寸法線とW・L・T表記

図面上のシート説明カードを外し、実測W（最大幅）・L（最大長）の寸法線へ変更しました。図面には切りしろや使用巻の説明を重ねず、シート番号と実測値を表示します。上部の「シートの実測寸法線を表示」で切替できます。切り出し寸法・必要量・使用巻は下部の一覧で確認します。

マスタと割り付けの規格をW・L・Tで表記します。長尺シートのW・Lはmの小数1位、Tのみmm。ロールカーペットのW・L・Tはmmの整数です。マスタ候補・新しく選択する仕上げの仕様、図面寸法・壁寸法・寸法別枚数・切出し一覧の単位表示を統一しています。切りしろの入力や微調整は従来のmm入力を保ちます。

元データはmm精度を保持し、表示だけを丸めます。寸法欄へフォーカスすると登録値の精度で編集でき、m入力はmmへ換算します。例：1820mmは通常1.8m、編集時1.82m。マスタの種類切替・無変更保存でも元の寸法を丸めません。DB v12と保存形式は変更せず、過去の見積や保存済み仕様テキストは書き換えません。

検証：107件の自動テスト、型検査・ビルド、Electron E2Eが成功。長尺シートのm小数1位・Tのmm、カーペットのmm整数、材料種類の切替、1820mmを保持した編集・無変更保存、実測のみの寸法線・切りしろとの区別、保存・復元・右パンを確認しました。Windows実機は未確認です。

## v0.15.0の切り出し順と巻き残り

長尺シート・ロールカーペットで「巻き残りを使って切出し順を調整」を追加しました。番号順の巻数と調整後の巻数を比較し、巻ごとの使用長・残り長と切出し順を一覧に表示します。初期状態はオフ。配置・シート番号・切出し長・必要延長と面積は変更せず、巻への割り当てのみ調整します。

番号順のnext-fitと、長いシートから既存巻の余りへ割り当てるfirst-fit decreasingを比較し、巻数が少なくなる場合だけ後者を採用します。同数または増加する場合は番号順を維持します。最少巻数を保証する探索ではありません。巻長未設定や長さ超過の場合は割当を算定しません。幅方向の端材再利用、複数の部屋をまたぐ割当、柄合わせは未実装です。

段差のある部屋で、帯の境界に接するだけの壁を切出し長へ含める問題も修正しました。帯の内部に入る外周線分から長さを求め、回転・逆回りの形状でも同じ長さにします。

配置JSONへreorderCutsを追加し、旧JSONではfalseを補います。DB v12へ退避付きで移行し、新しいJSONを旧アプリが誤って扱わないようにします。既存の行やJSONは移行時に書き換えません。

検証：106件の自動テスト、型検査・ビルド、Electron E2Eが成功。6m・6m・4m・4mを10m巻3本から2本にまとめる例、回転・逆回りの段差形状、100通りの切出し長で重複・欠落・巻長超過がないこと、旧v11移行と配置JSONの保持、オン／オフ・切出し表・右パン・保存・再表示・バックアップ復元を確認しました。Windows実機は未確認です。

## v0.14.0の長尺シート・ロールカーペット

種類・材料選択、芯割り・芯跨ぎ・壁寄せ、90°回転と任意角度、切りしろ、切出し表、方向矢印と番号を追加。図面全体表示はロール材のとき縦横の両方に合わせます。入力中の結果欄の変化で材料候補が閉じないよう、候補を入力欄へ追従させます。端材再利用・柄合わせ・幅の重ね代・穴の控除・横継ぎ位置の自動配置・見積数量への自動反映は次段階です。

## v0.13.0の基準点から壁までの寸法

layoutWallDimensionsが配置の実際のanchorとangleを使い、縦横4方向と部屋外周との最初の交点までをmmで計算します。凹形状・斜め壁・回転・移動に対応。基準点が壁上にある場合、室内方向は先の壁まで、外向きは0とし、部屋外では表示せず案内します。頂点の壁番号は測定方向を横切る壁を優先します。

図面上の寸法線はズームにかかわらず同じ文字・線幅で表示し、短い線の文字は左側一覧で確認します。表示切替は画面上の設定で、保存済みの配置や数量を変更しません。DBはv10のままです。

検証：96件の自動テスト、型検査・ビルド・書式チェック、Electron E2Eが成功。中心点からの四方向寸法、100mm移動の増減、ズームでの実寸保持、表示切替、部屋外の案内、既存操作を確認しました。画面画像も確認済みです。

## v0.12.0の仕様・規格の整理

マスタを仕様の自由記述と規格の幅・長さ・厚み（mm）に分離しました。寸法の固定ボタンを取り除き、各寸法は独立して空欄にできます。目地幅は割り付け時の候補選択・数値入力とし、材料切替で保持します。

材料選択時にmaterialSpecificationで仕様と規格を一つの文字列へまとめ、拾い出し・集計・見積、およびCSV・PDF・Excelで共用します。マスタの仕様は240文字、合成後の保存欄は400文字です。保存済みの数量・見積をマスタ変更で自動書き換えしません。

DB v10でmaterialsにtileThicknessMmを追加。旧仕様の文章・幅・長さは変更せず保持し、旧目地幅はバックアップ互換用に保持しますが新規割付の初期値には適用しません。移行前にbefore-schema-v10の退避を作成し、旧バックアップも検証・変換します。

検証：91件の自動テスト、型検査・ビルド・書式チェック、Electron E2Eが成功しました。仕様＋幅・長さ・厚み、一部寸法のみの登録、目地の保持、見積と集計PDF・Excelへの合成文字列の引き継ぎ、保存・旧DB移行・バックアップ復元を確認しています。Windows実機での操作確認は未実施です。
